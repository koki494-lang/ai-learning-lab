# NEXSKILL - 要件定義

## 機能要件

### 認証・アカウント
- [x] メール/パスワードによるログイン
- [x] 新規登録（管理者が許可したメアドのみ）
- [x] ログアウト
- [x] パスワード表示/非表示トグル
- [ ] パスワードリセット（ユーザー向け。現在は管理者ページのみ）
- [ ] パスワード変更機能

### コース・チャプター
- [x] コース一覧表示（カード形式 + 進捗バー）
- [x] コース詳細画面（チャプター一覧）
- [x] チャプター詳細画面（hook → goals → body → points → practiceWork）
- [x] チャプター完了/未完了の切り替え
- [x] ステータス管理（未学習 / 学習中 / 完了）
- [x] 新コース/チャプター追加時の自動マージ（既存進捗を保持）

### ホーム画面
- [x] ウェルカムカード（時間帯別メッセージ）
- [x] 全体進捗バー
- [x] 今日のおすすめ（未完了チャプター）
- [x] コース一覧

### 学習タブ
- [x] 全チャプター統計（達成率・完了数・残り数）
- [x] フィルタリング（すべて / 学習中 / 未学習 / 完了）

### マイページ
- [x] プロフィール表示（メアド）
- [x] 統計表示（全チャプター数・完了数・進捗率）
- [x] ログアウトボタン

### 管理者ページ（admin.html）
- [x] 管理者ログイン（kokisuto494@gmail.com のみ）
- [x] 許可メアド一覧表示
- [x] 許可メアド追加/削除
- [x] 全ユーザーの学習進捗一覧
- [x] パスワードリセットメール送信

## 非機能要件
- モバイルファースト（375px〜対応）
- GitHub Pages で静的ホスティング（サーバーサイド不要）
- Firebase compat SDK（CDN読み込み、ビルドステップなし）
- ページ読み込み速度は1ファイル構成のため高速
- Firestoreテストモードルール（2026年7月まで。本番化前に要修正）

## MVPで必須の機能（実装済み）
- 認証（ログイン/新規登録/ログアウト）
- 許可制アクセス
- コース/チャプター閲覧
- 進捗管理
- 管理者ページ

## 後回しにする機能
- プッシュ通知
- ユーザー別の詳細分析ダッシュボード
- コメント/質問機能
- チャプター内のクイズ/テスト機能
- ユーザープロフィール編集（アイコン・名前変更等）
- ダークモード
- 多言語対応
- PWA対応（オフラインアクセス）

## やらないこと
- ユーザーによるコンテンツ作成/投稿
- SNS機能（いいね・フォロー等）
- 決済機能（当面は無料）
- ネイティブアプリ化
- AI自動生成をユーザーに開放（コンテンツ品質管理のため）
