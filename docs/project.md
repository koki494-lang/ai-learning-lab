# NEXSKILL - プロジェクト概要

## アプリ名
NEXSKILL（ネクスキル）

## 位置づけ
本命事業ではなく「サブ事業／練習台」。詳細は `DIRECTION.md` を参照。

## コンセプト
「次の自分をつくるスキル学習」

## ミッション
副業に踏み出したい大学生に、AIとPCの基礎スキルを無料で与え、「何者でもない自分」から抜け出す最初のきっかけを贈る。

## 解決したい課題
- 副業を始めたい大学生が「まず何から」を知る手段がない
- 既存の学習サービスは高額・重い・続かないものが多い
- 管理者が許可した人だけが使えるクローズドな学習環境が必要

## ターゲットユーザー
- **メインターゲット**: 大学1〜2年生。副業に踏み出したいが何から始めればいいか分からず止まっている
- **利用シーン**: スマホ中心（モバイルファースト）、授業のスキマ時間
- **前提スキル**: PC/スマホの基本操作ができる程度

## 提供価値
1. **入り口の地図**: 散らばった無料情報の海で「まず何から」を一本道で示す
2. **コストゼロの第一歩**: 無料だからこそリスクなく副業の世界を覗ける
3. **正直さによる信頼**: 「稼ぎを本気で狙うならスクールへ」と上限を正直に開示する

## 絶対に守る前提条件
1. **シングルHTMLファイル構成**: index.html（メインアプリ）+ admin.html（管理者ページ）のみ。ビルドステップなし
2. **Firebase BaaS**: 認証（Auth）とデータ永続化（Firestore）はFirebase。サーバーサイドコードなし
3. **GitHub Pages デプロイ**: mainブランチpushで自動デプロイ
4. **コンテンツ追加はClaude Code経由のみ**: ユーザーがアプリ内からコンテンツを追加する機能はない
5. **既存ユーザーの進捗を壊さない**: コース/チャプター追加時、既存ユーザーのデータに影響を与えない設計
6. **許可制アクセス**: 管理者が `approved_emails` に登録したメアドのみ新規登録可能
7. **完全無料**: 収益化しない。課金導線・サブスク・買い切りは一切作らない
